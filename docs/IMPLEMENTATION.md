# 実装記録

## 現行版

- バージョン: 1.2
- Android applicationId: `jp.local.kintai`
- データ保存: Web Storage（氏名・対象月単位）
- 動作方式: Capacitorによる完全オフラインAndroidアプリ

## 実装済み

- 通常勤務、分割勤務、日跨ぎ勤務の時間計算
- 休憩時間、飲食代、詳細、その他4行、月次メモ
- 月次集計、前月複製、JSONバックアップ／復元
- A4勤怠表PDFの確認、保存、共有
- 1955～2027年の内閣府公開データによる日本の祝日判定
- 2028～2099年の規則ベース暫定祝日判定
- APK更新時に旧Service WorkerとCache Storageを解除する移行処理

## 互換性

- 保存キー `kintai:v1:*` を維持し、既存データとの後方互換性を保持する。
- applicationIdと既存のデバッグ署名を維持し、上書き更新できる構成とする。
- アンインストールやアプリデータ消去では端末内データが失われるため、事前バックアップを推奨する。

## 未確認事項

- 実機でのv1.1からv1.2への上書き更新と祝日表示は、利用端末側での最終確認が必要。
- 2028年以降の祝日は公式発表後に同梱CSVを更新する。
