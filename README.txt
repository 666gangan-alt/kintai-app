勤怠管理アプリ Ver.1

【主な機能】
・氏名、対象月の管理
・日別の出勤/退勤（2分割勤務対応）
・休憩時間、就業時間の自動計算
・休みチェック
・飲食代、詳細メモ
・月間の出勤日数/就業時間/休憩時間/飲食代の自動集計
・その他4件、月次メモ
・端末内へ自動保存（localStorage）
・前月データ複製
・JSONバックアップ/復元
・A4 PDF保存
・対応端末ではPDFを共有メニューからLINE/メール等へ共有
・PDF直接生成が利用できない場合は印刷画面から「PDFとして保存」へフォールバック

【使い方】
1. index.html をブラウザで開く
2. 氏名・対象月を入力
3. 日々の出退勤を入力
4. 「PDF保存」または「PDF共有」

【スマホアプリ化】
GitHub Pages等のHTTPSに配置すると、Chromeの「ホーム画面に追加」でPWAとして使えます。
APK化する場合は、このWebアプリをCapacitorで包む方法が最短です。

【注意】
データは基本的に使用端末のブラウザ内へ保存されます。端末変更やブラウザデータ削除に備えて、定期的に「バックアップ保存」をしてください。
