# 勤怠管理

現行バージョン：1.3（Figma UI・祝日対応・Androidネイティブ強制キャッシュ移行対応）

自分専用の、完全オフラインで動作するAndroid勤怠管理アプリです。日々の出退勤、分割勤務、休憩、飲食代、詳細を端末内に自動保存し、月次集計とA4勤怠表PDFを作成します。

## 主な機能

- 氏名と月ごとに端末内へ自動保存
- 通常勤務、分割勤務、日跨ぎ勤務、休みの入力
- 日本の祝日名表示（振替休日・国民の休日、2020・2021年の五輪特例を含む）
- 出勤日数、就業時間、休憩時間、飲食代の自動集計
- 31日固定・A4縦のPDF確認／保存／Android共有
- 全月分のJSONバックアップと復元
- 前月データの複製、月データの初期化
- Figmaデザインに準拠した入力・集計・PDF出力の3画面UI
- 一覧タップで開く、2回目勤務を含む日別編集シート
- Android Safe Area対応の下部固定ナビゲーション
- CDN、サーバー、ログイン、INTERNET権限なし

## 祝日データ

1955～2027年は内閣府公開の「国民の祝日」CSVをアプリ内へ同梱しています。2028年以降は固定日・曜日ルールと春分／秋分の近似式で暫定判定します。内閣府データ更新後は `data/official-holidays.csv` を差し替え、`npm run holidays:build` を実行すると `src/holidays.json` を更新できます。

祝日は赤系で祝日名を表示しますが、「休み」は自動で選択されないため祝日勤務も通常どおり入力できます。PDFでは列を増やさず曜日欄を「日・祝」のように表示します。

## データについて

勤怠データはアプリ内のWeb Storageに保存されます。アプリ更新や端末再起動では保持されますが、アンインストールやアプリデータ消去では失われるため、定期的に「バックアップ保存」を利用してください。

PDFとバックアップはAndroidのDocuments配下の `勤怠管理` フォルダーへ保存します。端末やファイル管理アプリにより表示名が異なる場合があります。

開発・再ビルド手順は [BUILD_APK.md](./BUILD_APK.md) を参照してください。
